# Android 离线副本接入新账号

## 存储与恢复包基线（2026-10-19）

- 新账号首次快照必须为版本 1、密钥代次 1。离线副本以独立保险库复制：生成新的 UUID、VMK、密码封装和 ABR1 封装，全量重新加密；保留业务实体 UUID、内容、关联、排序和回收站状态。原离线文件、原账号与原历史不变，新账号历史从首次快照开始。
- 复制前完整解密和验证源备份；新快照超过在线 1 MiB 限制时拒绝准备注册，原副本不变。目标本机已有会话、保险库或待同步内容时拒绝覆盖。
- 注册请求发出后先保留候选状态，结果未确认时禁止重新生成材料；保留当前材料并使用本机已有设备身份登录。实际响应丢失的故障注入演练仍留到最终验收。
- `AUTHBOX-RECOVERY-KIT` v1 明文材料包包含服务地址、平台账号、保险库 UUID、保存日期、备份格式版本、ABR1 及 8 个一次性 ABAC1，并区分两者用途；不包含登录密码、保险库密码、VMK 或加密备份。明文原码不加入本机账号状态或云端请求，只保存恢复码哈希和加密封装。
- 材料包不是备份文件；断云恢复必须另存对应的完整加密备份。注册成功才形成有效平台账号，重新生成或轮换后需更新材料，并保留历史备份的对应密钥。材料包扩展名已加入 Git 忽略规则。

## 界面及恢复包文件

- 从“备份与保险库”的已保存离线副本进入接入流程。先选文件，再输入源凭据、目标地址、用户名和两次一致的新密码；确认独立复制后才生成候选保险库。保存的材料全部读回一致后显示确认步骤，输入两次一致的登录密码及新邀请码注册。
- 普通空白账号注册也使用完整材料包，包含地址、账号、UUID、日期、格式和两类秘密。仅在内存显示本轮秘密，后台/锁定立即清除；异步操作跨过锁定后即便已返回前台，也不会重新显示旧材料。锁定后的候选密文仍保留，原离线副本不变。
- 未在系统选择器等待期间保留明文恢复包；用户先选择新文件，返回前台才生成和写入。写入失败、读回不符或生成期间锁定时不显示可确认材料，提示文件可能不完整并要求重新生成。界面要求将文件或抄写材料另存在手机外，不把文件写入等同于已完成设备丢失恢复。
