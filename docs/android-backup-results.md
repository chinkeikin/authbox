# Android 保险库备份与离线恢复

## 存储与加密基线

- 更换保险库密码或 ABR1 恢复密钥时，仅生成新的独立盐和主密钥封装，保留 VMK、保险库 UUID、密钥代次及未修改实体的密文；重新认证备份清单，不改变公共格式。
- 同步账号的封装变更保存到可继续编辑的本地加密 draft，原已同步快照保留；上传请求已经固定时禁止修改。导出只允许已解锁 manager，选择最新 draft/pending/已同步快照，并先验证完整性。
- 文件恢复使用独立的 `OfflineVaultStore`，不需要平台登录、原域名或原设备 Keystore；导入先完整解密和校验，再明确确认写入。替换已有离线副本需额外确认，普通同步账号及其待上传内容不受影响。
- 离线副本支持本地管理、单调增加本机版本和再导出，始终通过本机 Keystore 加密 AtomicFile 保存，不调用认证或同步服务。新进程默认锁定，未确认的解密预览在锁定时销毁。
- 新恢复密钥在本机用 256 位系统随机数生成，明确确认离线保存后才更新封装。旧备份继续使用原密码/恢复密钥解密，换新不能撤回旧文件。
- PHB110 `BackupStoreTest` 3 项通过，11.901 秒，覆盖更换封装、旧凭据拒绝、条目密文保留、只读与固定请求保护、预览确认、取消与错误密码不覆盖、新命名空间独立导入、进程重开及离线编辑。
- 独立 Node 使用公共协议解密 Android 生成的新密码封装和新恢复封装，核对 4 个业务实体及原密文，确认过期凭据被拒绝；手机合成测试输出随后删除。
- 开发/测试 APK 构建与 Lint 通过。文件选择器与界面集成在下一步记录，当前不以存储测试代替界面验收。

登录 Argon2id 32 MiB / t=3 / p=1、保险库 64 MiB / t=3 / p=1 保持不变，不引入依赖或云端资源。本轮仅做合成数据功能验证；摄像头实扫、真实迁移、故障恢复演练和发布验收按用户安排留到最后。
