# Android 保险库备份与离线恢复

## 存储与加密基线

- 更换保险库密码或 ABR1 恢复密钥时，仅生成新的独立盐和主密钥封装，保留 VMK、保险库 UUID、密钥代次及未修改实体的密文；重新认证备份清单，不改变公共格式。
- 同步账号的封装变更保存到可继续编辑的本地加密 draft，原已同步快照保留；上传请求已经固定时禁止修改。导出只允许已解锁 manager，选择最新 draft/pending/已同步快照，并先验证完整性。
- 文件恢复使用独立的 `OfflineVaultStore`，不需要平台登录、原域名或原设备 Keystore；导入先完整解密和校验，再明确确认写入。替换已有离线副本需额外确认，普通同步账号及其待上传内容不受影响。
- 离线副本支持本地管理、单调增加本机版本和再导出，始终通过本机 Keystore 加密 AtomicFile 保存，不调用认证或同步服务。新进程默认锁定，未确认的解密预览在锁定时销毁。
- 新恢复密钥在本机用 256 位系统随机数生成，明确确认离线保存后才更新封装。旧备份继续使用原密码/恢复密钥解密，换新不能撤回旧文件。
- PHB110 `BackupStoreTest` 3 项通过，11.901 秒，覆盖更换封装、旧凭据拒绝、条目密文保留、只读与固定请求保护、预览确认、取消与错误密码不覆盖、新命名空间独立导入、进程重开及离线编辑。
- 独立 Node 使用公共协议解密 Android 生成的新密码封装和新恢复封装，核对 4 个业务实体及原密文，确认过期凭据被拒绝；手机合成测试输出随后删除。
- 开发/测试 APK 构建与 Lint 通过。文件选择器与界面集成在下一步记录，当前不以存储测试代替界面验收。

登录 Argon2id 32 MiB / t=3 / p=1、保险库 64 MiB / t=3 / p=1 保持不变，不引入依赖或云端资源。本轮仅做合成数据功能验证；摄像头实扫、真实迁移、故障恢复演练和发布验收按用户安排留到最后。

## 文件与界面集成

- 锁定界面或“账号与设备”可进入“备份与保险库”。同步账号导出包含最新本机草稿；更换密码/恢复密钥后仍需正常同步才能更新云端。ABR1 可用于已有缓存解锁及登录后的下载解密。
- 使用 Android [Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files) 的 OpenDocument / CreateDocument；只处理用户选择的 content URI，不申请全盘存储访问，不读取 file/HTTP URI。选择器新建导出目标，应用关闭流后再读回核对；未完成或取消不报告成功。
- 文件读取上限 16 MiB，拒绝非法 UTF-8、未知格式和完整性异常；明文只在本机解密。导出不含账号密码、会话、原恢复材料或 Keystore 密钥。跨进程重建导致导出缓冲丢失时要求重新解锁导出，目标可能为空，不自动重放导出。
- PHB110 `BackupFilesTest` 1 项通过，1.323 秒：真实 ContentResolver 读写与读回核对、上限、UTF-8、外部 URI 拒绝、无效输入不覆盖已有导出。
- `BackupScreenTest` 2 项通过，14.059 秒：新密码两次确认、从草稿导出并解密核对、恢复密钥预览及不确认不写入、后台清空预览；另验证无需平台登录导入离线副本、显示验证码、本地收藏编辑、版本增加、没有同步写入入口及手动锁定。
- 文件选择器由 instrumentation 返回公开测试 URI，后续 ContentResolver、加密、确认和落盘均为真实路径；没有把这组测试称为用户真实文件或新手机灾难恢复验收。测试 provider 仅在测试 APK，debug 可见性声明不进入 release。
- 独立 Node 重新解密界面导出的文件，确认新密码可用、旧密码被拒绝、4 个实体与未修改的条目密文保持一致。合成输出核对后删除。
- 账号安全界面回归 2 项通过（8.625 秒），原取码/后台锁定界面回归 1 项通过（6.553 秒）。构建与 Lint 通过；最终结果随收尾记录追加。

当前只保留一份独立离线副本，替换前须明确确认并自行保存旧文件；普通同步账号数据不受影响。将离线副本接入新的平台账号同步尚待后续实现。
