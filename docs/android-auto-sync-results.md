# Android 自动同步验证

## 同步核心

- 已解锁且会话可用时检查云端 head；无本地修改才按固定版本下载，使用内存中 VMK 认证清单、实体与业务规则，再原子保存。无需保留密码，不重复派生密码密钥，密码哈希参数不变。
- 同一 VMK 的密码封装变化可以自动接收；主密钥代次变化暂停拉取，要求手动使用新密码或恢复密钥下载。回退、身份变化、快照版本不符、密文认证失败均不替换原缓存。
- 草稿提交前检查版本，落后则保留原草稿并标记冲突；最终提交仍受服务端 CAS 保护。已有固定 pending 先重试原请求，以取得幂等回执，不因云端前进而改写请求。比较或冲突未处理时禁止自动同步。
- PHB110（Android 15/API 35）`AutoSyncStoreTest` 4 项通过，16.364 秒；覆盖只读拉取与写入拒绝、封装变化、锁定、草稿冲突、比较暂停、处理后提交、受控丢响应后的固定请求重试、无效密文/回退拒绝及新代次暂停。
- Android 开发/测试 APK 构建及 Lint 通过。上述网络使用受控 transport、数据全为公开合成数据；不替代真实云端联调或最终故障恢复演练。

## 前台调度与操作保护

- 默认开启，可暂停并持久保存选择。解锁后、业务修改后和经过系统连通性验证的默认网络恢复后提前检查，空闲前台每 60 秒检查；所有同步与手动操作串行。
- 编辑弹窗、批量选择、导入预览、比较、文件页面和恢复材料展示期间暂停。自动检查不会清除手动操作消息、恢复材料或导入预览；设置页支持明确点击立即检查。
- IOException、5xx、408、429 按 5 秒起、随机抖动最多 25%、上限 5 分钟退避，切换网络不会提前消耗下一次重试。协议/认证/权限错误暂停；401/403 清除解锁明文并提示重新登录。
- 后台注销网络观察，默认立即锁定。请求阶段之间检查前台代次，锁定后不继续后续下载或提交；已经发出的请求可能完成，收到有效提交回执仍确认原请求，但不会重新显示明文。默认恢复前台必须重新解锁；显式选择普通列表短时宽限时按[本机保护规则](android-protection-results.md)恢复，后台仍不发起同步。
- 最终 `AutoSyncStoreTest` 5 项通过，23.147 秒；追加“签名挑战返回后暂停、不发送 commit、保留固定请求并原样续传”的检查。

- 最终 `AutoSyncScreenTest` 5 项通过，41.232 秒：自动拉取与提交、编辑期间暂停、设置页立即检查、开关持久保存、离线恢复、退避与周期边界、恢复材料保留、401 锁定，以及后台再返回后旧响应不继续下载、不重新暴露明文。
- `ManagementScreenTest` 2 项（17.233 秒）、`SecurityScreenTest` 2 项（9.289 秒）、`ScreenTest` 1 项（6.398 秒）回归通过。最终构建与 Lint 通过，0 错误、7 个原有版本提醒。没有新增依赖；新增的网络状态权限无需运行时授权。

首轮真实免费云端回归在既有设备授权测试中遇到 HTTPS EOF，未判通过；该轮临时 Worker、DO 和域名绑定已核对清理。后续使用全新环境复测，结果见下文。

## 真实免费云端复测

- 使用全新的临时环境与合成账号复测。PHB110 `CloudAutoSyncTest` 1 项通过，19.084 秒：manager 检查并提交为版本 9，reader 仅凭已解锁 VMK 认证拉取，同版本检查不重复下载。
- 另一管理设备提交并发版本 10 后，本机自动检查将原 draft 保持逐字节不变并标记冲突，未冻结新请求；reader 拉取最新快照。撤销该 reader 后，后续同步被服务端拒绝。
- 独立 Node 登录下载，核对 reader 接收的快照逐字节一致，解密并验证最终版本 10、并发分组名称、此前自动提交的账号备注，以及本地草稿中仍保留的另一份分组名称。
- 整轮 Android 云端 28 项检查通过；同时回归登录、设备权限、会话轮换、加密持久化、备份封装、独立复制注册及冲突历史。第二轮云端测试 APK 上的自动同步界面 5 项检查也通过，41.056 秒。
- 本机管理 API 连接在运行检查全部完成后的套餐复核与清理阶段曾失败。连接恢复后按同一报告和所有权标记执行 `--cleanup --android`，核对 Worker、SQLite DO 命名空间及测试域名绑定删除；随后只读复核 Workers 付费订阅数前后均为 0。验证工具补充清理恢复后的套餐复核，并保留原网络错误为 `recoveredFailure`，没有重新部署或将失败检查标为通过。
- 最终报告 `runtimeChecksPassed`、`freeTierRuntimeVerified`、`cleanupVerified` 均为 true。托管证书生命周期独立管理，仅核对域名绑定删除。

未新增依赖、开通付费套餐或部署生产服务；登录 Argon2id 32 MiB / t=3 / p=1，保险库 64 MiB / t=3 / p=1 均未变更。真实迁移和故障恢复演练仍留到功能开发完成后，本轮合成功能验证不替代最终验收。
