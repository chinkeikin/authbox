验证日期：2026年10月16日。本步未创建或修改任何 Cloudflare 服务、套餐或部署，继续沿用已通过可行性验证的 Workers Free + SQLite Durable Objects 路线。服务端 Argon2id 参数仍为 32 MiB、3 轮、并行度 1；保险库参数固定为 64 MiB、3 轮、并行度 1。

## 本地协议测试

Node 24.13.0 执行 `npm test`：37 项通过、0 失败。自动化覆盖包括：

| 类别 | 实际结果 |
| --- | --- |
| TOTP | RFC 6238 全部 18 个向量、6/8 位、非默认周期、前导零、时间边界和大于 32 位的计数器通过 |
| URI | HOTP、外部 URL、重复参数、未知参数、issuer 冲突、未知算法和坏 Base32 拒绝 |
| 密码派生 | 与 Node 原生 Argon2id 输出一致；中文、emoji、组合字符按原始 UTF8 处理，无规范化 |
| 恢复密钥 | 与 Node 原生 HKDF 输出一致；校验错误和未知恢复编码拒绝 |
| AES-GCM | 与 Node 原生 AES-GCM 输出一致；身份、类型、版本、密钥代次、nonce、密文、标签和错误密钥的改动拒绝 |
| 密码改封装 | 更换密码后当前实体仍可解密；旧离线备份仍使用旧密码或原恢复密钥 |
| 自包含备份 | 密码和恢复密钥均可离线恢复；账号、分组、标签及设置均被加密 |
| 清单认证 | 删条目、替换密文、改时间/应用版本或封装，即使重算文件摘要仍拒绝 |
| 防资源滥用 | KDF 固定参数、最多 4 个派生任务、文件大小/实体数/明文大小上限、规范编码及嵌套限制通过 |
| 导入完整性 | 截断、未知版本、重复 ID、混入其他保险库、重复 nonce、坏日期和坏摘要拒绝；逐条认证后才返回结果 |
| 独立固定向量 | Node 原生密码学生成的完整公开备份，可由协议库按两种途径恢复 |

## Chrome

已安装 Chrome 155.0.8059.41，Playwright 隔离资料，回环地址加载完整本地包。CSP 限制脚本来源，只为 WASM 编译开放所需权限；包加载后通过浏览器上下文断网，再执行协议验证。

- 全部 18 个 TOTP 标准向量通过。
- Node 生成的随机备份和固定向量均可用密码、恢复密钥解密。
- 离线恢复后得到预期测试验证码，异常 KDF 参数在派生前拒绝。
- Chrome 生成新随机密钥、封装、实体及认证清单，Node 用两种途径恢复后四类实体一致。
- 无页面脚本错误，结束后关闭隔离浏览器和临时 HTTP 服务。

这不是安装后的 Manifest V3 验收，扩展存储、受信任上下文、锁定和后台生命周期尚未实现。

## Android

用户选定 PHB110，Android API 35。通过独立 dex 和 app_process 执行 JCA AES-GCM、固定 SHA256 的 Bouncy Castle 1.86 Argon2id/HKDF，不安装 APK，不读取已有应用数据。

- Node 随机备份和公开固定向量均通过密码封装、恢复封装和认证清单校验，逐条解密四类实体。
- 修改实体 revision 导致 AAD 认证失败。
- Android 使用新随机盐及 nonce，重新生成两种 VMK 封装、全部实体、清单和文件摘要。
- Node 用两种途径恢复 Android 随机备份；实体与原始内容完全一致，恢复出的测试密钥生成预期 TOTP。Android 重新加密的固定向量也恢复一致。
- finally 删除手机临时 zip、输入样本及专用目录，并核对目录不存在。

这不是正式应用验收，Keystore、内存压力、应用线程调度、Room、设备锁定和进程重启仍待 Android 工程。

## 范围与后续

本步完成密码学容器和备份格式，未完成业务实体 schema、同步 CAS/幂等协议、只读权限、账号恢复码、认证会话、NAS 正式备份工具或真实网站登录。测试只使用公开或随机合成数据，没有迁移真实验证账号。

后续同步实现必须原子提交手机生成的认证清单、封装和实体，云端不持有 VMK，不能自行重建该清单；详见 [协议说明](protocol-v1.md)。仍需完成阶段 2 的业务和权限协议，再进入账号与同步服务。

完整本机报告位于 `.cache/protocol/browser/report.json` 和 `.cache/protocol/android/report.json`。已公开不含序列号、内网地址和凭据的 [结果摘要](protocol-results.json)；复现命令和公开向量见 [协议 v1](protocol-v1.md)。
