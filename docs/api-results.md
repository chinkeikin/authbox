# 账号与同步服务验证结果

2026年10月16日。服务核心实现位于 `services/api/src/`，使用 Workers Free + SQLite Durable Objects。没有开通 D1、R2、付费 Workers、短信或第三方认证服务，没有部署生产环境。

## 已实现和验证的边界

| 场景 | 实际结果 |
| --- | --- |
| 自定义账号密码 | 邀请注册、密码登录、错误密码、未知用户、登记设备重新登录通过；原始 UTF8 中文/emoji 密码可用 |
| 密码强度 | SQLite PHC 为 Argon2id v19、32 MiB、3 轮、并行度 1、32 字节输出；Node 原生 Argon2id 独立重算一致 |
| 注册原子性 | 触发器在创建会话时故意报错，账号、设备、快照、nonce 和邀请全部回滚；清除故障后同一请求成功 |
| Chrome 只读 | reader 对提交、审批/撤销设备、改密码、恢复码轮换及管理挑战均被拒绝；伪造 role/client_type 不能提权 |
| 新管理设备 | 带公钥 reader 经管理设备签名批准后旧会话作废，目标以私钥证明重新登录才取得 manager；无公钥 Chrome 不能批准 |
| 私钥证明 | 请求/会话绑定、已用挑战重放及过期挑战均拒绝，采用 WebCrypto P-256 ECDSA/SHA256 |
| 同步与幂等 | 完整快照原子提交，同 ID 同请求重试返回原结果，改请求返回 409；同版本并发写入仅一个成功 |
| 提交故障回滚 | 在幂等结果插入时故意报错，当前版本和原快照保持不变；故障移除后原签名可继续提交 |
| 删除与恢复 | 移除记录的 ID 被登记，默认重新加入失败；显式历史恢复成功且版本继续递增 |
| nonce 防重用 | 使用历史 nonce 改动实体遭 409 拒绝，当前快照不变 |
| 用户隔离 | 第二个用户只读到自己的密文；跨用户设备撤销失败，userId 查询参数拒绝 |
| 刷新与撤销 | 刷新替换访问及刷新令牌，旧刷新重用撤销整个会话族；撤销立即阻止旧令牌和请求重试 |
| 密码修改 | 旧密码重认证、新 PHC 准备、设备签名确认及旧会话撤销通过；通用挑战不能绕过此流程 |
| 账号恢复 | 故障时恢复码消费、密码和授权全部回滚；同一码并发恢复仅一次成功，旧设备失效，保险库内容仍可解密 |
| 恢复材料轮换 | 原有恢复码失效，禁止将旧哈希装回并重新激活 |
| 重启与时间 | DO abort 后快照、设备、会话和限速持久保留；挑战 90 秒、访问 10 分钟、刷新闲置 30 天/绝对 90 天按边界失效 |
| 历史窗口 | 31 天后的旧游标返回 410，旧快照返回 404，当前快照仍可读 |
| HTTP 与部署 | Origin/CORS、重复键、坏输入和大体拒绝，慢请求测试超时；正式包排除测试接口，Wrangler dry-run 通过 |
| 持久层检查 | SQLite 中没有合成密码、原始会话令牌、恢复码原文、保险库恢复密钥或业务名称；服务端只保存必要身份和密文 |

## 本地证据

`npm test` 执行 46 项协议测试、2 项 HTTP 单元测试、157 项 workerd/SQLite 接口检查和 9 项正式入口检查，均通过。157 项包含测试控制检查，两组并发各算一个检查项，不等于 HTTP 请求总数。正式入口另行检查注册、reader 登录、只读写入拒绝和注销，排除 fixture token、改时钟、注入故障和哈希审计代码。

故障注入、时间推进和 SQLite 审计仅存在独立 `test/fixture-worker.mjs`。事务使用真实 `transactionSync`，没有以 mock 数据库替代。共享静态 WASM 构建器移到 `tools/bundling/`，旧探针入口保留兼容导出。

## 免费云端正式入口

在已有授权子域名创建临时 Worker 与 SQLite 类，运行和本地相同的 157 项检查，全部符合预期。测试入口另有随机凭据及 30 分钟实际时间失效保护，时钟推进只作用于对象内的业务时间。

部署前后读取订阅，Workers 付费订阅均为 0；命名空间注册表确认 `use_sqlite: true`。CPU 按对象日志标签关联到 6/10 个预设 KDF 调用，均为 `outcome=ok`：

| 调用 | CPU ms |
| --- | ---: |
| 注册主账号 | 228 |
| 错误密码 | 195 |
| 候选手机登录 | 220 |
| 登记手机私钥登录 | 181 |
| 注册第二账号 | 175 |
| 会话过期后手机重新登录 | 187 |

未收到 reader-login、unknown-user、password-prepare、recover-rollback 四个预设标签的可关联 CPU 日志。功能均通过，但不补填耗时，不声称所有认证路径已采齐。这些是实际样本，不是公开并发容量或长期 SLA 验收。

早期轮次出现过入口 403、控制面读取 500 和测试故障控制 503，未记作通过。后续改用真实来源 IP、控制面 GET 有限重试和固定故障触发器控制记录，完整复测通过；失败原始报告保留在本机忽略目录。

各轮临时 Worker、SQLite 命名空间与域名绑定均已核对删除。托管证书生命周期独立，没有声称证书已删除。公开 [结果摘要](api-results.json) 不含账户 ID、域名、序列号、密码、令牌或恢复材料。
