# Android 设备与账号安全

## 实现范围

- 管理设备读取本账号设备列表，对照完整设备 ID 后批准持有公钥的只读手机；获批手机须用密码和本机 Keystore 私钥重新登录。没有公钥的只读设备不提供批准按钮。
- 撤销设备需要二次确认；撤销本机后清除本机登录会话并锁定，保留加密缓存。联网撤销不能抹去对方离线取得的内容。
- 平台密码修改复用既有 prepare/confirm：验证当前密码，核对服务端准备的挑战上下文并签名，获得新会话。确认请求结果不明时标记会话不可自动刷新，保留新旧密码并重新登录。
- 新账号恢复码在本机生成 8 个，每个 128 位随机值；明确勾选离线保存后才上传域分离 SHA256。准备阶段不作废旧码，原码仅在当前界面内存展示，后台锁定清除。
- 账号恢复使用一个 ABAC1 码、新平台密码和新的设备 ID/Keystore 签名。服务端单次消费并撤销全部旧设备与会话；本地保险库密文和待同步修改保留，恢复账号本身不解密保险库。
- 恢复新身份先作为候选持久保存；明确失败保留旧身份，成功才替换。结果不确定时保留候选，使用新密码和本机已有设备身份登录以确认，避免自动反复消费恢复码。
- 密码和恢复码输入框隐藏明文，离开应用时关闭并清空相关对话框。恢复需明确确认会撤销全部旧设备；密码两次输入必须一致，不对密码 trim 或规范化。
