# Android 本机保护记录

## 已实现的策略

- 后台锁定默认为立即，可选 15/30/60 秒。后台界面和输入立即清空，只有未编辑、未比较、未展示恢复材料且没有进行中操作的普通保险库可短暂保留内存解锁；超时、手动锁定、熄屏、Activity 销毁及进程重启后重新解锁。同步账号与独立离线副本分别维护期限，恢复前再检查单调时钟，不能依靠后台计时器准时执行。
- 闲置锁定默认为 5 分钟，可选 1/15 分钟；只由用户交互延长，TOTP 刷新、网络回调和自动同步不延长。设置仅存本机，不上传保险库。
- 验证码复制标记为敏感数据，写入随机所有权标记。默认 30 秒清理，可选 15/60 秒；只在当前剪贴板仍匹配本应用的标记及写入时间时清除，不覆盖后来复制的内容。只持久保存标记、写入时间和到期信息，不保存验证码。
- 系统不允许后台读取剪贴板时，返回并获得焦点后复核清理；进程重建后重新读取待清理信息。后台精确定时清理不作保证，参照 [Android 剪贴板访问限制](https://developer.android.com/privacy-and-security/risks/secure-clipboard-handling)。复制按钮使用当前仍解锁的保险库状态复核，锁定后的旧界面回调不能复制。

## 系统便捷解锁的实现与验证边界

- 已接入同步账号和独立离线副本。先用保险库密码或恢复密钥解锁，再通过系统认证启用；本机 AES-256-GCM Keystore 密钥配置为每次操作均需要强生物识别或设备锁屏凭据，使用 CryptoObject 绑定实际加解密，不能仅凭一个“认证成功”布尔值解锁。
- 只落盘认证密钥封装后的 VMK，外层继续使用本机 Keystore AtomicFile。封装绑定应用、本机命名空间、保险库 UUID、主密钥代次和密码/恢复密钥封装摘要；封装变化后需重新启用。取消、超时、返回桌面、熄屏和销毁会清理未完成请求；返回前台后才处理成功结果，随后仍完整认证备份内容。
- 关闭便捷解锁删除本机封装和对应密钥；退出同步账号、替换离线副本也清除对应封装，不删除加密备份。该功能不代替平台登录、设备授权或新设备恢复材料。
- 本次按 Android 11/API 30 及以上实现认证绑定的强生物识别/设备凭据组合；Android 8–10 保留原密码与恢复密钥入口，不采用无认证密钥作为替代。认证组合的版本边界见 [Android 系统认证规范](https://developer.android.com/identity/sign-in/biometric-auth)。没有新增第三方依赖或降低密码派生参数。
- PHB110 初次运行认证密钥用例时，Keystore 明确拒绝：未设置安全锁屏。用户选择暂不设置并把真实系统认证留待后补。因此本轮只验收未配置时的安全拒绝与密码回退，不把认证成功、强生物识别、PIN 返回、系统密钥失效和认证中的生命周期场景标为通过。

先安装开发/测试 APK，再运行 `npm run verify:android:app:protection`。工具记录设备认证条件，选择对应的拒绝测试或认证密钥测试，并始终将 `positiveAuthenticationVerified` 保持为 false；只有后续用户在手机上完成真实系统认证验证后，才能补记正向结果。

## 已验证结果与后补项

- PHB110（Android 15/API 35）检测为 `deviceSecure=false`、认证状态 11。`QuickUnlockUnavailableTest` 2 项通过（14.289 秒）：未设置锁屏不生成便捷解锁密钥、不写入 VMK 封装，原密文和业务数据不变，锁定后密码解锁仍正常。
- `ClipboardTimerTest` 1 项通过（20.066 秒）：点击实际取码按钮，等待真实 15 秒后剪贴板清除，锁定后旧回调拒绝复制。`LocalProtectionTest` 覆盖标记、时间与持久到期信息核对，后来复制内容保留，失去焦点时不擅自读取/清理，重新获得焦点后核对。
- 闲置到期后，恢复、复制和首次触摸均先检查锁定，不允许用到期后的第一次触摸延长旧解锁。测试仅将自身窗口保持亮屏，不更改系统休眠、安全锁屏或认证配置。初始界面等待曾超时，改为显式等待初始化与前台可操作状态后复测，不把它归因于密码哈希。
- 离线编辑入口的快速 Home/返回测试曾失败；修正为点击敏感入口时同步标记，不等待重绘帧，并为独立离线副本接入同一交互保护。修正后 `LocalProtectionTest` 4 项通过（20.940 秒），`BackupScreenTest` 2 项通过（15.671 秒）；普通列表可按宽限返回，离线编辑及粘贴导入后立刻 Home/返回保持锁定。独立 Node 解密实际导出，核对新密码、实体密文不变及旧密码拒绝。
- 真实强生物识别、PIN/图案/密码认证成功、认证中的 Home/熄屏/重建、设备密钥失效和关闭系统安全锁屏的场景未实测。认证密钥正向前置测试 `QuickUnlockStoreTest` 保留，但本轮不计为通过。

云端和密码哈希实现未改动，保持 Workers Free + SQLite Durable Objects；登录 Argon2id 32 MiB / t=3 / p=1、保险库 64 MiB / t=3 / p=1。
